Run the analysis file to obtain all the statistical analyses of the article, as well as the graphical representations of the results.

The data_grooming file contains the data used for the analyses.

The “Raw data” folder contains all the original data in .xlsx format, including both focal and hierarchy data.

The “ECP data” folder contains all the data used to generate Figure 2 of the article.

The “Data for Gephi” folder contains all the .gephi files used to represent the social network of the macaque group.
